RAIDDR_Basic_DDR5_4MD_4CW.v
 RTL code for implementing a RAIDDR Encoder/Decoder for DDR5 with 4 metadata bits
 Consists to two parts to the file.
 1) A program-generated header (generated by RaiddrBasic_InitRTL code)
 2) A generic Basic RAIDDR file (authored by Brett.Dodds@microsoft.com)

RAIDDR_Basic_DDR5_4MD_4CW_tb.v
 RTL test code for the RAIDDR_Basic_DDR5_4MD_4CW.v RTL code
 Includes testing of various patterns, several known ECC gaps
 Easily modified to evaluate more
