# BasicRAIDDR

#### BasicRAIDDR (RAID for DDR) error correction code

## Overview

BasicRAIDDR is a symbol-based error correction code that provides optimal correction and detection capability for ECC-provisioned blocks of data.

## Files and Folders

README.md --> This file  
RAIDDR_Code_Enablement.docx --> Detailed description of enabling BasicRAIDDR in hardware  
RaiddrBasic_InitRTL --> Code for automated RTL generation based on user inputs  
RaiddrBasic_RTL --> Example full RTL code and test code for a specific DDR5 implementation  
RaiddrBasic_Validate --> C code for Basic RAIDDR simulation in software
